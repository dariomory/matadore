# Installation

## Stable release

To install matadore, run this command in your terminal:

```sh
uv add matadore
```

Or if you prefer to use `pip`:

```sh
pip install matadore
```

## From source

The source files for matadore can be downloaded from the [Github repo](https://github.com/dariomory/matadore).

You can either clone the public repository:

```sh
git clone https://github.com/dariomory/matadore
```

Or download the [tarball](https://github.com/dariomory/matadore/tarball/main):

```sh
curl -OJL https://github.com/dariomory/matadore/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd matadore
uv sync
```
